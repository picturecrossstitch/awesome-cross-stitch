# Awesome Cross Stitch

A list of tools and resources for counted cross stitch: turning photos into charts, editing charts, keeping track while you stitch, thread color data, free patterns and places to learn.

Every link was checked when it was added. If something is gone or there's a good tool missing, open an issue or a pull request.

> This list is kept by the people who make [Picture Cross Stitch](https://picturecrossstitch.com), which appears below. Other entries are here because they're useful, not because they're paid or affiliated.

## Photo to pattern

Websites that turn a photo into a chart with thread numbers.

- [Picture Cross Stitch](https://picturecrossstitch.com) - Photo to DMC chart in the browser, no account. Crop, set the size, cut the colors, remove the background, fix single stitches. Free preview, PDF $4.99.
- [Pic2Pat](https://www.pic2pat.com) - Free photo to pattern converter, quick and simple.
- [Pixel-Stitch](https://www.pixel-stitch.net) - Photo conversion with DMC and Anchor colors.
- [Thread-Bare](https://www.thread-bare.com) - Photo converter known for its dithering. Paid per pattern.
- [Stitchmate](https://stitchmate.app) - Pattern maker and editor that aims for less confetti. Pattern Keeper compatible PDFs.
- [Xstitchify](https://xstitchify.com) - Charts from photos, text and QR codes, plus a stitch tracker.
- [Stitchboard](https://www.stitchboard.com) - Free pattern wizard and a large library of user-made patterns.

## Chart editors

For drawing a chart from scratch or editing one stitch by stitch.

- [Stitch Fiddle](https://www.stitchfiddle.com) - Online chart editor for cross stitch, knitting and crochet. DMC and Anchor.
- [FlossCross](https://flosscross.com) - Free online editor with image import and PDF export.
- [WinStitch and MacStitch](https://www.ursasoftware.com) - Desktop software for Windows and Mac from Ursa Software. They also make the free MiniStitch.
- [PCStitch](https://www.pcstitch.com) - Long-running Windows charting software.

## Open source

- [KXStitch](https://github.com/KDE/kxstitch) - KDE's cross stitch pattern and chart editor. C++, GPL-2.0.
- [Embroiderly](https://github.com/embroidery-space/embroiderly) - Cross-platform desktop app for designing cross stitch patterns.
- [xstitch](https://github.com/jbweston/xstitch) - Tools for generating counted cross stitch patterns. Haskell, AGPL-3.0.

## Apps for stitching from a chart

Mark off what you've stitched on a PDF chart instead of with a highlighter.

- [Pattern Keeper](https://patternkeeper.app) - Android app that reads PDF charts and tracks progress by color.
- [Markup R-XP](https://www.markuprxp.com) - Chart markup app for iOS and Android.

## Thread color data

- [Craft Color Codes](https://github.com/makebead/craft-color-codes) - Hex and RGB values for DMC floss and bead brands, as JSON and CSV, with a color matcher.
- [Stitchies thread conversion charts](https://getstitchies.com/tools/printable-charts) - Printable charts for converting between thread brands. CC BY 4.0.
- [DMC color chart](https://picturecrossstitch.com/dmc-color-chart) - All 489 DMC colors with numbers and names, searchable.
- [DMC](https://www.dmc.com) - The thread maker's own site.

Screen colors are only close to real thread. When it matters, check against a printed card or the skeins themselves.

## Free patterns

- [Picture Cross Stitch free patterns](https://picturecrossstitch.com/cross-stitch-patterns) - Original charts by theme (Christmas, animals, flowers, Halloween and more), each a free PDF with a DMC thread list.
- [Gathered](https://www.gathered.how/needlework/cross-stitch) - Free charts and projects from the UK craft magazines.

## Learn and ask

- [Lord Libidan](https://lordlibidan.com) - Guides, software reviews and thread tools from a long-time stitcher.
- [Needlepointers pattern generator list](https://www.needlepointers.com/main/ShowArticles.aspx?NavID=3289) - More than 20 pattern makers, free and paid.
- [r/CrossStitch](https://www.reddit.com/r/CrossStitch/) - Big, friendly community. Read the [FAQ](https://sites.google.com/view/rcrossstitchfaq) first.
- [Needle 'n Thread](https://www.needlenthread.com) - Hand embroidery techniques, videos and stitch tutorials.
